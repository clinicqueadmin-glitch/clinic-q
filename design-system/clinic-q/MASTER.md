## KEY EFFECTS

- **Shadows:** Subtle, layered (not heavy)
  - `--shadow-sm`: `0 1px 2px rgba(0,0,0,0.05)`
  - `--shadow-md`: `0 4px 6px -1px rgba(0,0,0,0.1), 0 2px 4px -2px rgba(0,0,0,0.1)`
  - `--shadow-lg`: `0 10px 15px -3px rgba(0,0,0,0.1), 0 4px 6px -4px rgba(0,0,0,0.1)`
- **Border Radius:** Consistent, soft
  - `--radius-sm`: 6px (buttons, inputs)
  - `--radius-md`: 10px (cards)
  - `--radius-lg`: 16px (modals)
  - `--radius-xl`: 24px (large modals)
  - `--radius-full`: 9999px (badges, avatars)
- **Transitions:** 150-200ms ease-out for interactions
  - `--transition-fast`: 150ms ease-out
  - `--transition-normal`: 200ms ease-out
  - `--transition-slow`: 300ms ease-out
- **Focus Rings:** 3px solid teal with 2px offset (keyboard accessible)

## ANTI-PATTERNS (AVOID)

- ❌ Dark mode as primary (healthcare = bright, clean, trustworthy)
- ❌ Heavy gradients or glassmorphism (distracting in clinical settings)
- ❌ Emoji as structural icons (use Lucide SVG icons)
- ❌ Neon colors or high saturation
- ❌ Complex animations that slow workflow
- ❌ Small touch targets (< 44px)
- ❌ Color-only status indicators (always add icon/text)
- ❌ Dense information without clear hierarchy

---

## PRE-DELIVERY CHECKLIST

- [ ] No emojis as icons (use Lucide React)
- [ ] cursor-pointer on all clickable elements
- [ ] Interaction timing follows platform conventions
- [ ] Text contrast 4.5:1 minimum (WCAG AA)
- [ ] Focus states visible for keyboard navigation
- [ ] prefers-reduced-motion respected
- [ ] Text, chips, and badges reflow without clipping
- [ ] Responsive: 375px, 768px, 1024px, 1440px
- [ ] Touch targets ≥ 44px on mobile
- [ ] Form labels visible (not placeholder-only)
- [ ] Error messages near related fields
- [ ] Loading states for async operations
- [ ] Empty states with helpful actions

## COMPONENT PATTERNS

### Queue Card
- Status-colored left border (4px)
- Queue number in monospace, large, bold
- Patient name as primary text
- Clinic type as colored badge
- Time and doctor as secondary info
- Action buttons: Call (green), Skip (gray), Complete (green), Delete (red)

### Stats Card
- Icon in colored circle background
- Large number (3xl, bold)
- Label (sm, secondary text)
- Change indicator (up/down arrow + percentage)

### Modal
- Backdrop blur + dark overlay
- Rounded corners (16px)
- Header with title + close button
- Scrollable content area
- Footer with action buttons

### Toast Notification
- Slide in from right
- Color-coded by type (success/error/info)
- Auto-dismiss after 3 seconds
- Close button for manual dismiss
